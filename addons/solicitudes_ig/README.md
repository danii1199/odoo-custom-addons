# Solicitudes IG (`solicitudes_ig`)

Para cancelar tus solicitudes de seguimiento pendientes de Instagram, a mano pero rápido. No se conecta a Instagram.

1. En Instagram: **Centro de cuentas → Tu información y permisos → Descargar tu información** → «Seguidores y
   seguidos» (HTML o JSON). En el zip: `connections/followers_and_following/pending_follow_requests.html`.
2. En **Solicitudes IG** (menú del sitio, solo con permiso): importa ese archivo (o pega los nombres).
3. **Abrir siguientes 10** abre 10 perfiles en pestañas. En cada uno: *Solicitado → Dejar de seguir*. Luego
   «✓ Todas las del pack, canceladas».
4. Al cabo de unos días, descarga otra exportación e impórtala: lo que ya no salga queda resuelto y lo que siga
   pendiente vuelve a la lista.

La primera vez, el navegador puede bloquear las pestañas: permite las ventanas emergentes para tu sitio.
